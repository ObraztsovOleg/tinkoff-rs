# Исследовательский архив стратегий

Каталог связывает каждую встроенную стратегию с собственным русским PDF-разбором
и с метаданными академических публикаций. Разборы хранятся в Git; полные тексты
чужих статей — только в персональном локальном кэше.

Это библиотека реализованных гипотез, а не рейтинг прибыльности. Стратегии не
проходили локальный бэктест на MOEX, а опубликованный эффект на другом рынке не
гарантирует будущий результат.

## Что находится в Git

- `manifest.toml` — названия, авторы, DOI, landing page, допустимый прямой PDF
  URL, способ получения, известный режим распространения и связь со стратегией;
- `briefs/*.ru.md` — 15 оригинальных русских разборов;
- `briefs/*.ru.pdf` — PDF-версии тех же разборов;
- `permissions/` — место для письменных разрешений правообладателей.

Каталог `originals/` исключён из Git и используется как персональный локальный
кэш. Наличие прямой ссылки в manifest не означает права перепубликовать файл.

## Как хранить оригиналы

Готовые PDF-разборы уже находятся в `briefs/`; пересбирать или проверять их
отдельной командой не требуется. Полные оригиналы необязательны и не участвуют
в сборке, CI или работе торгового runtime.

Если статья получена законным способом, её PDF нужно вручную поместить в
`docs/research/originals/`. Имя файла берётся из `expected_filename` соответствующей записи
`[[paper]]` в `manifest.toml`. Например, для `id = "moreira-muir-2017"` указано
`expected_filename = "moreira-muir-2017.pdf"`, поэтому итоговый путь будет
`docs/research/originals/moreira-muir-2017.pdf`.

## Правила получения и распространения

1. Пользователь получает статью самостоятельно без обхода paywall, авторизации или
   иных ограничений. `manual` означает, что оригинал добавляется в `originals/` вручную.
2. Наличие URL в manifest не даёт права коммитить original. По умолчанию все
   оригиналы считаются непригодными для распространения без разрешения.
3. Файл можно перенести в отслеживаемый каталог только при проверенной
   разрешающей лицензии либо письменном разрешении в `permissions/`.
4. Рабочие статьи NBER остаются персональными копиями согласно указанным в
   manifest условиям. SSRN-файл также не перепубликуется.
5. Собственные briefs пересказывают идеи и формулы своими словами и не содержат
   длинных заимствованных фрагментов.

## Формат manifest

Каждая `[[paper]]` содержит стабильный `id`, `role` (`primary`, `critique` или
`context`), список `strategies`, библиографию, источники и ожидаемое локальное
имя. Пустой `pdf_url` намеренно означает ручное получение. `brief_pdf` либо
`brief_pdfs` связывает primary source с одним или несколькими из 15 разборов.

Локальные оригиналы не входят в воспроизводимую сборку и не используются CI.
Сведения об официальных источниках и ожидаемых именах файлов находятся в
`manifest.toml`; отдельный индекс персонального кэша не создаётся.
