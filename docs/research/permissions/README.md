# Permissions

Сюда помещаются письменные разрешения правообладателей на распространение
конкретного оригинального PDF. Само наличие URL, DOI или персонально скачанной
копии разрешением не считается.

Перед переносом стороннего PDF из gitignored `../originals/` в отслеживаемый
каталог нужно зафиксировать здесь источник разрешения, правообладателя,
разрешённый объём распространения и дату.
